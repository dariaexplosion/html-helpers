Закрыть инструмент паролем

Загружаешь .html-файл хелпера → задаёшь пароль → скачиваешь зашифрованную версию. Оригинал не трогается. Всё шифрование происходит прямо в этом браузере — файл никуда не отправляется.

📁 Перетащи .html файл сюда или нажми, чтобы выбрать
✓ Готово! Файл скачан — залей его на GitHub вместо оригинала.

Как это работает: файл шифруется алгоритмом AES-256 прямо на твоём компьютере. В репозитории на GitHub будет лежать нечитаемая шифрованная версия — открыть код страницы или посмотреть файл в репозитории без пароля не получится.

Важно: пароль общий для всех, кому его дашь — это не отдельные логины с возможностью отозвать доступ у одного человека. Чем длиннее и небанальнее пароль, тем лучше. Если забудешь пароль — расшифровать файл без него будет невозможно, сохрани оригинал отдельно.
