Схема полей: location · source · target · id · fuzzy · context · translator · developer_comments — та же, что в «Проверке таблиц локализации», файлы совместимы между инструментами. Галочка «только source + target» урезает .xlsx/.csv до двух столбцов.
CSV: при чтении сначала ищутся заголовки из той же схемы полей (как в .xlsx) — если не находятся, первая колонка считается source, вторая — target. Разделитель — запятая, кодировка на выходе — UTF-8 с BOM (чтобы Excel сразу показывал кириллицу правильно).
Как поля ложатся в XLIFF: context → атрибут resname, fuzzy → approved="no", location → context-group/sourcefile, developer_comments и translator → отдельные <note> с from="developer"/"translator".
Ограничения: множественные формы (plural) в .po сворачиваются в одну строку (msgstr[0]); устаревшие записи (#~) не читаются; заголовок .po при конвертации из json/xlsx создаётся заново по умолчанию.
